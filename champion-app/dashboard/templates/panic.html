Key Leak Help

If an Alpaca key may have leaked, work through these steps in order.
{{ALERTS}}

Step 1 — STOP ALL

Stop the engine first, before anything else. STOP ALL halts every order; it does not sell anything you already hold.

{{STOP_BLOCK}}

Step 2 — Regenerate at Alpaca

Go to https://app.alpaca.markets, sign in, and regenerate the API key pair for each affected account (paper and live are separate pairs). Regenerating invalidates the old pair immediately — any script still using the old secret will receive HTTP 401. Then audit your orders and positions at Alpaca and cancel anything you do not recognise.

Step 3 — Replace the keys in config.local.json

On this machine, open config.local.json and replace the old key id and secret key with the new pair, for each account you regenerated. Save the file. Never paste keys into a website, chat, or email — they only ever go into this local file, by your own hand.

Note: after replacing keys, live mode must be re-enabled deliberately from the Trading Mode page. Existing broker clients are revoked by design when the keys change, so nothing trades on the new pair until you re-enable it yourself.

Step 4 — Verify the new keys

Check that each account with keys in the config can be reached with those keys. This places no orders — it only reads the account.
